This database system was developed for Crownfield Eye Hospital to manage patient, staff, appointment, treatment, and billing information efficiently. 
The database uses a normalised relational structure to reduce data redundancy and improve data integrity. 
SQL queries, joins, transactions, and security controls have been implemented to support hospital operations. 
The system provides reliable data storage, retrieval, and reporting while maintaining confidentiality and accuracy of patient records.
